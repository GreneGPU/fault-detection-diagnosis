# Fault Detection and Diagnosis in Engineering Systems

MATLAB analysis of process faults using principal component analysis and dynamic monitoring methods.

**Tools:** MATLAB, PCA, DPCA.

## Project focus

- Apply multivariate monitoring to process measurements
- Compare normal operation and multiple fault cases
- Evaluate fault detection and diagnosis results

## Using the materials

Open the scripts in MATLAB and set the working directory to the relevant materials folder. The models may require the toolboxes used in the original coursework.
